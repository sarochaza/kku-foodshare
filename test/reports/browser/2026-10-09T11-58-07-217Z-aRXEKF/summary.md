# ผลทดสอบ Browser

เวลาในชื่อโฟลเดอร์และ JSON ใช้ UTC / ISO

**ผ่าน 9 ชุด | ไม่ผ่าน 0 | ไม่ได้รัน 0**

| ไฟล์ | สิ่งที่ทดสอบ | ผล | 
|---|---|---|
| about-image-check | ตรวจไฟล์ภาพหน้าเกี่ยวกับเรา การอ้างอิงภาพใน template ข้อความทดแทนภาพ และสัดส่วนภาพใน CSS | PASS |
| admin-posts-check | ตรวจการแสดงผล UI หน้าจัดการโพสต์ของแอดมินด้วยข้อมูลจำลอง | PASS |
| dark-surfaces-check | ตรวจการแสดงผลพื้นหลังและข้อความในธีมมืดด้วยข้อมูลจำลอง | PASS | 
| onboarding-check | ตรวจการแสดงผลกล่องคำแนะนำเริ่มต้นและการโต้ตอบกับคำแนะนำด้วยข้อมูลจำลอง | PASS | 
| phase10-ui-check | ตรวจ UI ที่ปรับใน Phase 10 จาก template/CSS และการแสดงผลหน้าเว็บด้วยข้อมูลจำลอง | PASS | 
| pickup-reminder-check | ตรวจการแสดงผล UI แจ้งเตือนรับอาหารด้วยข้อมูลจำลอง ไม่รวมการส่งอีเมลจริง | PASS | 
| browser-journey | ทดสอบสมัครสมาชิกและล็อกอิน ค้นหาสถานที่ เลือกพิกัด สร้างโพสต์พร้อมรูป แก้ไขโพสต์ ค้นหาอาหารและหมุดแผนที่ คำแนะนำเริ่มต้น เส้นทางเดินทาง จองและแก้จำนวน เจ้าของยืนยันรับอาหาร แก้โปรไฟล์ และการแจ้งเตือน รวมถึงกรณีบริการแผนที่ขัดข้อง การปฏิเสธสิทธิ์ตำแหน่ง และการแสดงผลหลายขนาดจอ | PASS | 
| quick-actions-journey | ทดสอบจองและแก้จำนวนจากหน้าโพสต์โดยรักษารหัสจองและรหัสรับ เปิด QR แจกอาหารออฟไลน์โดยรักษาสต็อกที่ถูกจอง แก้จำนวนที่แจกผิด ป้องกันการปรับจากข้อมูลสต็อกเก่า ยกเลิกและคืนสต็อก สแกน QR ยืนยันรับ เพิ่มอาหารเพื่อเปิดโพสต์อีกครั้ง และลบอาหารที่ไม่ได้แจก รวมถึงการกู้สถานะเมื่อคำตอบ API ขาดหายและการแสดงผลบนมือถือ 320px | PASS | 
| home-overflow-check | ตรวจหน้าแรก กล่องคำแนะนำ การเลื่อนหมวดหมู่ และการเปิด/ปิดตัวกรองอาหารที่ยังรับได้ ว่าไม่ล้นจอขนาด 360, 390, 768 และ 1366px | PASS |

## หลักฐานและขอบเขตการทดสอบ

- `logs/` เก็บรายละเอียดการรันทั้ง 9 ชุด
- `screenshots/` เก็บภาพหน้าจอที่ชุดทดสอบบันทึก
- `reports/` เก็บรายงานรายละเอียดเพิ่มเติมของแต่ละชุด โดยบางชุดไม่ได้สร้างรายงานเพิ่มเติม
- จำนวน 9 หมายถึงชุดสคริปต์ แต่ละชุดอาจตรวจหลายขั้นตอน
- มีทั้งการตรวจไฟล์ source การใช้ข้อมูลจำลอง และการใช้งานเว็บ local ผ่าน Playwright ที่ `http://localhost:8081`
- ผลที่ใช้ข้อมูลจำลองไม่ยืนยันการทำงานของ API หรือบริการภายนอกจริง ส่วนชุดที่ทดสอบกับเว็บ local ยังจำลองบริการภายนอกบางส่วน
