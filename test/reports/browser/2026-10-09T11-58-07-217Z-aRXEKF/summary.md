# ผลทดสอบ Browser

เวลาในชื่อโฟลเดอร์และ JSON ใช้รูปแบบ ISO 8601 โดยอ้างอิงเวลา UTC

**ผ่าน 9 ชุด | ไม่ผ่าน 0 ชุด | ไม่ได้รัน 0 ชุด**

| ไฟล์ | สิ่งที่ทดสอบ | ผล |
|---|---|---|
| about-image-check | ตรวจการอ้างอิงไฟล์ภาพในหน้าเกี่ยวกับระบบจากซอร์สโค้ด | PASS |
| admin-posts-check | ตรวจหน้าแสดงรายการโพสต์สำหรับผู้ดูแลระบบด้วยข้อมูลจำลอง | PASS |
| dark-surfaces-check | ตรวจการแสดงผลพื้นผิวและองค์ประกอบของหน้าเว็บในธีมมืดด้วยข้อมูลจำลอง | PASS |
| onboarding-check | ตรวจการทำงานของคำแนะนำเริ่มต้นใช้งานและการโต้ตอบกับกล่องคำแนะนำด้วยข้อมูลจำลอง | PASS |
| phase10-ui-check | ตรวจองค์ประกอบและการแสดงผล UI ที่ชุดทดสอบ Phase 10 ครอบคลุมด้วยข้อมูลจำลอง | PASS |
| pickup-reminder-check | ตรวจการแสดงผลแจ้งเตือนรับอาหารและการเปิดรายการจองที่เกี่ยวข้องด้วยข้อมูลจำลอง | PASS |
| browser-journey | ทดสอบเส้นทางใช้งานบนเว็บจริง: สมัครและเข้าสู่ระบบ สร้างและแก้ไขโพสต์ อัปโหลดภาพ ค้นหาและใช้แผนที่ จองและแก้ไขจำนวน ยืนยันรับอาหาร แก้ไขโปรไฟล์ การแจ้งเตือน และการรองรับข้อผิดพลาด โดยบางบริการแผนที่ใช้ข้อมูลจำลอง | PASS |
| quick-actions-journey | ทดสอบการจองและยกเลิกจากหน้าโพสต์ การแสดง QR การปรับสต็อกสำหรับแจกหน้างาน การป้องกันกระทบจำนวนที่จองไว้ การจัดการข้อมูลสต็อกล้าสมัย และการแสดงผลบนหน้าจอขนาดเล็ก | PASS |
| home-overflow-check | ตรวจหน้าแรกที่ความกว้าง 360, 390, 768 และ 1366 พิกเซล ให้คำแนะนำ หมวดหมู่ และตัวกรองแสดงผลโดยไม่ล้นหน้าจอในแนวนอน | PASS |

ภาพหน้าจอเก็บใน `screenshots/` และรายงานเพิ่มเติมเก็บใน `reports/` เฉพาะชุดที่สร้างไฟล์เหล่านี้ จึงไม่จำเป็นต้องมีรายงานเพิ่มเติมครบทั้ง 9 ชุด โดยดูผลรวมได้จาก `summary.json` และ Log ของแต่ละชุดใน `logs/`

**ผ่าน 9 ชุด หมายถึงสคริปต์ทดสอบ 9 ไฟล์ทำงานสำเร็จ ไม่ใช่มีเพียง 9 กรณีทดสอบ**

การตรวจซอร์สโค้ดและการใช้ข้อมูลจำลองไม่ได้ยืนยันการทำงานของ API จริง ส่วนชุดที่ไม่ได้เลือกให้รันจะมีสถานะ `NOT_RUN`
