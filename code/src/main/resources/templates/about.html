อาหารที่ยังดี
ควรได้ไปอยู่บนโต๊ะอาหาร

บางครั้งมีอาหารเหลือจากมื้อประชุม งานกิจกรรม หรือการเตรียมอาหารมากเกินไป ขณะเดียวกันก็มีคนที่กำลังมองหามื้อถัดไป FoodShare ช่วยเชื่อมสองฝั่งเข้าด้วยกันผ่านข้อมูลอาหาร จำนวน เวลารับ และตำแหน่งนัดรับ

ผู้แบ่งปันเป็นผู้กำหนดรายละเอียดและจำนวนที่ให้จอง ผู้รับเลือกจองเท่าที่ต้องการ แล้วนัดรับตามเวลาที่ระบุ
