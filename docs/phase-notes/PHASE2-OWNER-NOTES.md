# Phase 2 — Owner Management

เวอร์ชันนี้ต่อยอดจาก Phase 1 ที่ใช้งานได้ โดยคงระบบบัญชี การจอง สต็อก ฐานข้อมูล และชื่อ Compose project เดิมไว้

## สิ่งที่เพิ่ม

- ศูนย์จัดการฝั่งผู้โพสต์ พร้อมจำนวนโพสต์ที่เปิดอยู่ จำนวนที่รอมารับ และจำนวนที่ส่งมอบแล้ว
- ทางลัดสแกน QR จากหน้า “โพสต์ของฉัน” โดยไม่ต้องเปิดผู้จองทีละโพสต์
- สแกนจากกล้องจริงบนเบราว์เซอร์ทั่วไป โดยใช้ตัวอ่านฝั่งเซิร์ฟเวอร์เมื่อ `BarcodeDetector` ไม่มี
- เลือกรูปหรือภาพหน้าจอ QR จากเครื่องได้
- หน้าตรวจสอบชื่อ รูปโปรไฟล์ รายการ จำนวน จุดรับ และเวลานัดรับก่อนยืนยัน
- การ์ดผู้จองแบบละเอียด พร้อมสถานะและรูปโปรไฟล์
- แถบความคืบหน้าการส่งมอบ ตัวกรองโพสต์ และปุ่มสแกนลอยบนมือถือ
- ยังคงกรอกรหัส 6 หลักเป็นทางเลือกสำรอง

## เริ่มใช้งานบนเครื่องเดิม

เปิด PowerShell ในโฟลเดอร์โปรเจกต์ แล้วรัน:

```powershell
docker compose -p kku-foodshare-phase1 up --build -d
docker compose -p kku-foodshare-phase1 ps
```

จากนั้นเปิด <http://localhost:8081/account/posts>

การใช้ Compose project ชื่อเดิมจะสร้าง image/app เวอร์ชันใหม่ แต่ยังใช้ volume ฐานข้อมูลเดิม จึงไม่ลบข้อมูลเดิม เว้นแต่จะสั่ง `docker compose down -v` เอง

## วิธีทดสอบสองบัญชี

1. เปิดบัญชีผู้โพสต์ในหน้าต่างปกติ
2. เปิดบัญชีผู้รับใน Incognito/InPrivate หรืออีกเบราว์เซอร์
3. ให้บัญชีผู้รับจองอาหารและเปิด QR ในหน้า “การจองของฉัน”
4. บัญชีผู้โพสต์เปิด “โพสต์ของฉัน” แล้วกด “สแกน QR เพื่อส่งมอบ”
5. ถ้า QR อยู่บนจอเครื่องเดียวกัน ให้บันทึกภาพ QR แล้วใช้ “เลือกรูป QR จากเครื่อง”
6. ตรวจรายละเอียดผู้รับ แล้วกด “ยืนยันว่าส่งมอบแล้ว”

หากกล้องไม่เปิด ให้ตรวจสิทธิ์กล้องของเบราว์เซอร์สำหรับ `localhost:8081` แล้วโหลดหน้าใหม่

## การตรวจสอบที่เพิ่ม

- Unit test สำหรับรูปแบบ QR และตัวถอด QR จากภาพ
- Integration test สำหรับ endpoint สแกนภาพ
- Integration test ว่าเฉพาะเจ้าของโพสต์หรือผู้จองที่เกี่ยวข้องเท่านั้นที่เห็นรูปผู้จองได้
- Regression test ว่าหน้า Owner workspace มี scanner และ shortcut ครบ
