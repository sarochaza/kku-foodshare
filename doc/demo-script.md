# Demo และโครงนำเสนอ

## Demo 7–10 นาที

1. เปิดหน้าแรกบนโน้ตบุ๊กและมือถือ อธิบายปัญหาอาหารเหลือและการค้นหาจุดรับ
2. ผู้แบ่งปันเข้าสู่ระบบ สร้างโพสต์ ใส่รูปและเลือกหมุดจริง
3. เปิดบัญชีผู้รับในอีกเบราว์เซอร์ ค้นหา/กรอง/ดูแผนที่ จองจำนวน 2
4. แสดงจำนวนคงเหลือลดลง รหัสรับแสดงเฉพาะผู้รับ
5. เปลี่ยนจำนวนหรือยกเลิก แสดงการคืน stock และการแจ้งเตือน
6. จองใหม่ ผู้แบ่งปันกรอกรหัส ส่งมอบ แล้วแสดงจำนวนรับแล้ว
7. แสดงสิทธิ์: สมาชิกทั่วไปเปิด admin ไม่ได้ ผู้ดูแลปิดโพสต์จากรายงานพร้อมเหตุผล
8. เปิด Swagger, migration, ผล tests และอธิบาย post lock + idempotency

ใช้โพสต์ที่ระบุชัดว่า “ข้อมูลสำหรับสาธิต” ใน environment ทดลอง ไม่ปะปนกับอาหารที่พร้อมรับจริง

## Slide outline (10 หน้า)

1. ชื่อโครงการ + ชื่อสมาชิก/รหัสจริง
2. ปัญหาและกลุ่มผู้ใช้
3. Use cases และขอบเขต
4. UI responsive + เส้นทางหลัก
5. Layered architecture และ dependency flow
6. ER diagram 9 ตาราง + constraints
7. SOLID และ Strategy/State/Observer ในโค้ดจริง
8. Reservation sequence, race protection และความปลอดภัย
9. ผลการทดสอบที่รันจริง + ข้อจำกัด
10. Deployment topology, public URL เมื่อเผยแพร่จริง และแนวทางพัฒนาต่อ

เติม URL cloud, repository, บทบาทสมาชิก และข้อมูลทีมตามจริงก่อนนำเสนอ
